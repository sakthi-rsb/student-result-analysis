# Student Result Analysis System

## About the Project

The Student Result Analysis System is a data analysis project built using Python and MySQL. It analyzes student marks, calculates average scores, identifies pass and fail results, and compares department performance.

## Technologies Used

* Python
* MySQL
* Pandas
* Matplotlib
* VS Code

## Features

* Store student details and marks in MySQL.
* Retrieve student results using SQL queries.
* Calculate total marks and average marks.
* Analyze pass and fail results.
* Compare average performance across departments.
* Visualize student performance using charts.

## How to Run

1. Install Python.
2. Install the required libraries:
   `pip install mysql-connector-python pandas matplotlib`
3. Create the MySQL database and tables.
4. Update the MySQL connection settings in `student_analysis.py`.
5. Run the program:
   `python student_analysis.py`
